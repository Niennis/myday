# Mi día

Organizador personal de escritorio para Windows (Tauri 2 + React + TypeScript). El contexto completo, las decisiones y el siguiente paso están en el plan.

@docs/PLAN.md

## Reglas del proyecto

- **Menos es más.** Antes de agregar una opción, pregunta si es imprescindible. La persona dejó de usar otros organizadores por tener demasiadas opciones.
- **Tono amable.** Nada de rojo para lo atrasado, ni mensajes que culpen.
- **Liviano.** Cuida el consumo de memoria y CPU: la app queda abierta todo el día.
